# Checklist Rossi Formatura

Aplicativo web responsivo para cadastrar itens de estoque, organizar materiais por formatura e salvar ou imprimir cada checklist em PDF.

## Acesso e dados

- O app funciona sem login.
- O estoque e os eventos são compartilhados pelo banco Supabase.
- Qualquer pessoa com o link pode consultar e alterar os dados compartilhados.
- Não armazene dados sensíveis neste app enquanto o acesso estiver público.
- Os organizadores podem receber apenas o PDF do checklist.
