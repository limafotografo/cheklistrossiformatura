# Checklist Rossi Formatura

Aplicativo web responsivo para cadastrar itens de estoque, organizar materiais por evento e imprimir ou salvar o checklist em PDF.

## Publicar com GitHub Pages

1. Abra **Settings > Pages** deste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
4. Após a publicação, acesse: https://limafotografo.github.io/cheklistrossiformatura/

Os dados do app ficam armazenados localmente no navegador usado (localStorage).
